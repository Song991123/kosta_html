CSS Grid Template Areas

이 예제는 ex14_grid.html을 바탕으로 새 파일을 만든 뒤, grid-template-areas를 사용한 배치와 반응형 변화를 보여준다.

1. grid-template-areas 기본 예제

각 박스에 이름을 붙여 두면, 숫자 대신 영역 이름으로 레이아웃을 설계할 수 있다. 화면이 좁아지면 미디어 쿼리로 영역 배치를 다시 정의해 반응형으로 바뀐다.

Header

상단 전체를 차지하는 헤더 영역

Sidebar

왼쪽 메뉴나 카테고리 영역

Content

본문이 들어가는 메인 콘텐츠 영역

Gallery

이미지 목록이나 카드 묶음을 표현하는 영역

Footer

하단 안내 문구나 링크를 담는 푸터 영역

2. Hover 시 전체 영역을 차지하는 Grid 예제

아래 카드에 마우스를 올리면 해당 카드가 그리드 전체를 덮고, 나머지 카드는 보이지 않게 된다. Grid 안에서 아이템이 확장되는 효과를 확인할 수 있다.

A 마우스를 올리면 전체 영역으로 확대된다.
B 다른 카드는 숨겨지고 현재 카드만 남는다.
C :hover와 Grid 배치를 함께 사용한 예제
D 작은 화면에서도 동일한 방식으로 동작한다.
E 수업용 데모로 확장 효과를 확인하기 좋다.
F 마우스를 떼면 다시 원래 그리드로 돌아온다.
