이벤트 처리하기

이벤트는 클릭, 입력, 마우스 올리기처럼 사용자 행동이 일어났을 때 실행되는 기능임.

이 페이지는 이벤트 등록 방법과 요소 찾는 방법을 같이 보여주는 예제임.

1. 태그에 바로 등록

HTML 태그에 onclick을 직접 적는 방식임.

빠르게 테스트할 때는 편함. 하지만 HTML과 JS가 섞임.

inline event

<button onclick="showInlineEvent()">클릭 1</button>

언제 씀

간단한 테스트 초기 학습

2. JS에서 on이벤트명 등록

element.onclick = 함수 형태로 등록하는 방식임.

한 요소에 간단히 연결할 때 씀. 같은 이벤트를 덮어쓸 수 있음.

property event

const btn = document.getElementById("btn-property");
btn.onclick = function () {
	addLog("property 방식 실행");
};

언제 씀

빠른 연결 덮어쓰기 가능

3. addEventListener 등록

addEventListener()는 가장 많이 쓰는 방식임.

이벤트를 여러 개 붙이기 좋고, 유지보수도 편함.

addEventListener

const btn = document.getElementById("btn-listener");
btn.addEventListener("click", function () {
	addLog("listener 방식 실행");
});

언제 씀

실무에서 자주 씀 여러 이벤트 등록 가능

4. event 객체 사용

이벤트가 일어났을 때 어떤 요소인지 알고 싶을 때 씀.

클릭한 대상, 타입 같은 정보를 확인할 수 있음.

event object

btn.addEventListener("click", function (event) {
	console.log(event.target);
	console.log(event.type);
});

5. window.onload

window.onload는 화면 준비가 끝난 뒤 실행되는 함수임.

이미지, CSS, HTML까지 다 읽고 나서 시작하고 싶을 때 씀.

page load event

window.onload = function () {
	addLog("페이지 준비 완료");
};

6. body 안 요소 찾는 방법

이벤트를 등록하려면 먼저 요소를 찾아야 함.

  • document.getElementById("id명") : id 하나 찾을 때 씀.
  • document.getElementsByClassName("class명") : class 여러 개 찾을 때 씀.
  • document.getElementsByTagName("태그명") : 태그 이름으로 찾을 때 씀.
  • document.querySelector("css선택자") : 첫 번째 요소 하나 찾을 때 씀.
  • document.querySelectorAll("css선택자") : 조건에 맞는 요소를 전부 찾을 때 씀.

querySelectorAll + forEach 예제

document.querySelectorAll("button")은 버튼들을 전부 찾음.

forEach는 찾은 요소를 하나씩 꺼내서 반복함.

ele는 현재 버튼 요소임. index는 순서 번호임.

같은 자리에서 mouseover, mouseout 이벤트도 같이 등록할 수 있음. 

document.querySelectorAll(".foreach-demo-buttons button").forEach(function (ele, index) {
	ele.innerText = "버튼 " + (index + 1);
	ele.style.backgroundColor = "#0ea5e9";

	ele.addEventListener("mouseover", function () {
		ele.style.transform = "translateY(-3px)";
	});

	ele.addEventListener("mouseout", function () {
		ele.style.transform = "translateY(0)";
	});
});
