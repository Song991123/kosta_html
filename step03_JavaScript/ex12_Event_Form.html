form 제출 + event.preventDefault() 비교 예제

같은 form이라도 그대로 제출할지, JavaScript로 제출을 막을지에 따라 결과가 달라짐. 왼쪽은 action으로 실제 전송하는 예제이고, 오른쪽은 event.preventDefault()로 이동을 막고 화면에만 전송되었습니다.를 보여주는 예제임.

form element action submit JSON preview preventDefault demo

1. action으로 실제 전송

이 폼은 submit 시 브라우저가 action 주소로 실제 이동함. 새 탭에서 임시 응답 화면이 열리도록 target="_blank"를 사용함.

설명

아직 전송 전임. 입력하면 오른쪽 JSON 미리보기가 먼저 바뀜.

action 폼 JSON 미리보기

실제 제출 전에 현재 전송될 데이터를 JSON 형태로 보여줌.

action: https://httpbin.org/post 

					


					

						
언제 씀?

						
    
							
  • 폼이 실제로 어디로 전송되는지 보여주고 싶을 때
    • 
							
  • name 값이 서버로 넘어가는 key라는 점을 설명할 때
    • 
							
  • submit 기본 동작을 먼저 이해시키고 싶을 때
    • 
						

					

				

			


			

				

					
2. preventDefault로 제출 막기

					

						이 폼은 submit 이벤트 안에서 event.preventDefault()를 호출함.
						그래서 페이지 이동이나 새 탭 열림 없이, 화면에
						전송되었습니다.만 보여줌.
					


					

						
						

						

							

								
								
							


							

								
								
							


							

								
								
							


							

								
								
							


							

								
								
							

						


						

							
							
						

					


					

						아직 submit 전임. 버튼을 누르면 여기 문구가 바뀜.
					


					

						
왜 씀?

						
    
							
  • 폼 기본 이동을 막고 직접 검증할 때
    • 
							
  • AJAX / fetch 전송 전에 화면 제어를 하고 싶을 때
    • 
							
  • 제출 성공 메시지를 현재 페이지에만 보여주고 싶을 때
    • 
						

					

				


				

					
코드 설명 같이 보기

					

						주석만 넣는 대신, 중요한 코드 의미를 화면에서도 바로 읽을 수 있게 정리함.
					


					

						

							
action submit

							

								event.preventDefault()를 쓰지 않으면 브라우저가 form의
								기본 동작을 실행함.
							

						

						

							
preventDefault submit

							

								submit 이벤트를 가로채서 이동을 막고, 현재 화면에서 안내 문구나 검증
								로직을 실행함.
							

						

					


					

						
// 1) action으로 실제 전송하는 form
                        actionForm.addEventListener("submit", function () {
                            updatePreview(actionForm, actionPreview, actionSentAtInput);
                            actionStatus.innerText = "전송 시작됨. 새 탭에서 JSON 응답을 확인하면 됨.";
                        });

                        // 2) 기본 제출을 막는 form
                        preventForm.addEventListener("submit", function (event) {
                            event.preventDefault();
                            updatePreview(preventForm, preventPreview, preventSentAtInput);
                            preventMessage.innerText = "전송되었습니다.";
                        });

					


					

						
핵심 한 줄 정리

    • 
							
  • method="post"는 데이터를 본문에 담아 보냄
    • 
							
  • event.preventDefault()는 form 기본 제출을 막음
    • 
							
  • 
								막은 뒤에는 JS로 원하는 메시지나 검증 결과를 직접 보여줄 수 있음
