# HTML & CSS Practice

기초 HTML, CSS 학습 내용을 정리한 실습 저장소입니다.  
예제 파일을 직접 만들고, 레이아웃과 스타일링을 단계별로 연습하는 목적의 프로젝트입니다.

## Preview

이 저장소에서는 아래와 같은 내용을 연습합니다.

- HTML 기본 문서 구조
- 목록, 표, 이미지, 링크, 폼
- CSS 적용 방식
- 박스 모델
- `display`, `float`
- `flex`
- `grid`
- 간단한 페이지 레이아웃 구성

## Folder Structure

```text
html 프로젝트
├─ step01_HTML   : HTML 기초 예제
├─ step02_CSS    : CSS 기초 및 레이아웃 예제
├─ 과제          : 과제 및 템플릿 파일
├─ 실습          : 추가 실습 파일
└─ img           : 이미지 리소스
```

## Study Notes

- 예제들은 학습용으로 작성되어 있어 구조와 속성을 확인하기 쉽도록 구성되어 있습니다.
- 일부 파일은 내부 스타일(`<style>`) 방식으로 작성되어 CSS 개념을 바로 비교하며 볼 수 있습니다.
- Grid, Flex 예제는 레이아웃 동작을 눈으로 확인하기 좋게 색상과 영역을 나누어 두었습니다.

## How to Use

1. 원하는 `.html` 파일을 브라우저에서 엽니다.
2. 코드 편집기에서 HTML/CSS를 수정해 봅니다.
3. 화면이 어떻게 변하는지 직접 확인하며 학습합니다.
